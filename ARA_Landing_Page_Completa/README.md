# A.R.A. Landing Page

Landing page estática para divulgação pública temporária do projeto.

## Testar localmente
```powershell
cd ara_landing_page
python -m http.server 5500
```
Abra `http://localhost:5500`.

## Antes do deploy
1. Substitua as logos em `assets/` pelas versões originais se desejar.
2. Adicione domínio/canonical/Open Graph quando o domínio definitivo estiver configurado.
3. Publique atrás de HTTPS.
